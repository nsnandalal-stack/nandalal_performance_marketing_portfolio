# Nandalal — Interactive 3D Performance Marketing Portfolio

An immersive portfolio experience built with Three.js and static assets, designed for GitHub Pages.

## Deploy

This repository is configured for static hosting. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Local preview

Run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000`.

## Notes

The Three.js modules are loaded from a CDN, so the site requires an internet connection. The project is an interactive prototype; the lead portrait is used as a visual character reference and is not a fully rigged photorealistic 3D model.
